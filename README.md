# MPAZticket
REPOSITORIO PROYECTO PARA COLEGIO MARCELA PAZ.

En este repositorio documentamos el desarrollo del proyecto solicitado para el colegio Marcela Paz
en el cual se nos solicita que la aplicación pueda ser utilizada tanto por personal del colegio como para apoderados.

-----------------------------------------------------------------------------------------------------

Para esto se espera de nuestra aplicación que permita a los funcionarios registrar un problema, categoría, ubicación y descripción para obtener un numero de ticket con su respectivo tipo de estado, como puede ser: Pendiente, Aprovado, Rechazado, Finalizado y Cancelado.


También la app permite ver el registro de los tickets desde el panel de inspectoría. Para así poder visualizar quien genero tal ticket, por ejemplo: RES-8156 - Inspector General.

Para así ir manteniendo un registro claro de quien genero tal ticket etc.

Para la persistencia de datos utilizamos una base de datos.
